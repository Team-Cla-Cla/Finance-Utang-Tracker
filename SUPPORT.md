# Support

## Where to get help

- **Bug reports:** Open a [bug report](https://github.com/Team-Cla-Cla/Finance-Utang-Tracker/issues/new).
- **Feature requests:** Open a [feature request](https://github.com/Team-Cla-Cla/Finance-Utang-Tracker/issues/new).
- **Security concerns:** Follow [SECURITY.md](SECURITY.md).
- **Setup and usage:** Check the [README](README.md), [FEATURE_GUIDE.md](FEATURE_GUIDE.md), and [DDD.md](DDD.md) first.

## Include useful details

When reporting a problem, include:

- Whether you used the web app, PWA, extension, or CLI
- Browser, operating system, and relevant versions
- Steps to reproduce the problem
- Expected and actual behavior
- Safe console or command output

Remove OAuth tokens, private spreadsheet links, personal financial data, and other sensitive information before posting.
