# Changelog

All notable changes to this project are documented here.

This project follows the format described by [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-24

Production release v1.0.0 ready for Firefox Add-ons Developer Hub and GitHub Pages.

### Added

- Streamlined modular client presentation layers and dedicated canvas rendering subsystems (ambient orbs, Conway's Game of Life, telemetry overlay).
- Production-ready offline-first Service Worker with automatic cache invalidation and single-page navigation fallback.
- Defensive validation across transactions, debts, stashes, and calendar day inspectors.
- Automated client DOM and architecture validation test suite.

### Changed

- Replaced colored metrics emoji button with a minimalist, theme-matching SVG vector bar chart.
- Bumped release version to `1.0.0`.

## [0.9.1] - 2026-09-24

This is the first public Firefox Developer Hub release baseline. The version intentionally starts at `0.9.1` while the project is being validated for distribution.

### Added

- Responsive offline-first web app and installable PWA
- Cross-browser WebExtension client
- Allowance, expense, debt, repayment, stash, and analytics workflows
- Optional direct Google Sheets synchronization with OAuth
- Shared browser-compatible domain services for ledger, debt, stash, and sync rules
- Settings control to pause and resume the live Conway background animation
- Clear action for the Record Expense note field
- GitHub Pages deployment and automated JavaScript validation
